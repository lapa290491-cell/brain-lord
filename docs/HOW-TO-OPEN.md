# Как открыть карту мозга с планшета

1. Открой эту ссылку в Chrome:
   https://htmlpreview.github.io/?https://github.com/lapa290491-cell/brain-lord/blob/main/docs/brain.html

2. Если белый экран — подожди 5 секунд и обнови страницу.

3. Нажми кругок на карте. Внизу появится, что делает этот агент.
4. Кнопка «Скопировать правку» — вставь текст в чат Grok.
